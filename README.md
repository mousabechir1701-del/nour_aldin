here# نور الدين - رفيق المسلم

تطبيق ويب إسلامي تفاعلي يعمل من ملف واحد (`index.html`) على الجوال والمتصفحات، مع وضع داكن وفاتح، ويحفظ إعداداتك محليًا في متصفحك.

## المميزات
- **المصحف الشريف:** قارئ صفحات المصحف المدني (1–604) مع تحقق بنيوي من الآيات، فهرس السور، الانتقال لصفحة أو آية، علامة مرجعية، ونسخ الآية. تُحفظ الصفحات التي قرأتها على جهازك لإعادة قراءتها دون اتصال.
- **مواقيت الصلاة والقبلة:** حساب المواقيت بمكتبة [Adhan JS](https://github.com/batoulapps/adhan-js) (طريقة رابطة العالم الإسلامي)، وزاوية القبلة من إحداثيات جهازك.
- **الأذكار والمسبحة:** أذكار الصباح والمساء والنوم (من حصن المسلم) مع عدد التكرار وعدادات يومية، والأذكار القرآنية تُفتح من المصحف الموثّق، ومسبحة إلكترونية.
- **المظهر:** وضع داكن وفاتح، وتحكم بحجم خط المصحف.

## التشغيل
افتح `index.html` في أي متصفح حديث. تحديد الموقع يتطلب `https` أو `localhost`، فالأفضل التشغيل عبر GitHub Pages أو:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع جديد.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. يظهر التطبيق على `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

## الاعتماديات (تُحمَّل من الإنترنت)
| المورد | الاستخدام |
|---|---|
| [Quran.com API v4](https://api.quran.com) | نص المصحف وترقيم الصفحات |
| Adhan JS 4.4.3 (jsDelivr) | مواقيت الصلاة |
| Font Awesome 6.4.0 (cdnjs) | الأيقونات |
| Google Fonts (Amiri, Tajawal) | الخطوط |

> التطبيق لا يعمل بالكامل دون اتصال: النص المحفوظ يُقرأ دون إنترنت، لكن الخطوط والأيقونات ومكتبة المواقيت تحتاج اتصالًا عند أول تحميل.

## تنبيه علمي
- نص المصحف مصدره Quran.com وتُفحص بنيته فقط (الانتماء، الترتيب، التكرار، النقص). **لم تتم مقارنة الحروف والتشكيل بنسخة مجمع الملك فهد**؛ تلزم مراجعة بشرية قبل اعتماده للنشر العام.
- نصوص الأذكار ومصادرها موسومة داخل التطبيق «قيد المراجعة» وبعضها مقتطع، وتلزم مراجعتها على كتب السنة الأصلية.
- قارن المواقيت بالتقويم الرسمي في بلدك.
